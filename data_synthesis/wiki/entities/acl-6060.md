# ACL 6060 (dev eval set)

The held-out evaluation set (TED-talk derived), English source with 4 reference languages
(zh / ja / de). Used by [[checkpoint-evaluation]] for all latency-quality scoring. Files under
`datasets/acl_6060/` and `/data/group_data/li_lab/siqiouya/datasets/acl_6060/dev/text/txt/`.

Note: on ACL 6060 dev, BLEU/chrF is biased toward conservative set-intersection surface forms —
rank by COMET ([[comet-vs-bleu-ranking]]).
